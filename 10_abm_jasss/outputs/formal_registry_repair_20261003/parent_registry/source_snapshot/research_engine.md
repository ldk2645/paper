## 2 Tick边界与因果顺序

快照边界为 `boundary_before_delivery`；tick `t`代表即将开始的周期，`run(until=t)`已完成0至t−1。在一个tick内依次发生：

1. 评价器记录消费和漂移前的总体平均偏好 `P_true[t]`。
2. 交付 `available_at <= t` 的公开包、调查及规则披露；最新有效公开包替换旧包，缺失包仍记录接收但不抹掉旧有效包。
3. 政府使用历史公开包及对应窗口末公开内容目录，按更新频率和证据签名更新估计；不符合更新条件时保持自身估计。
4. 到监测tick时，政府根据自己的估计新增计划；已在pending中的话题阻止重复排期。随后执行到期计划，因此零行政延迟允许在本tick新增并执行，但不能获得本tick未来信号。
5. 回应执行可调节目标话题的普通内容热度，并独立控制是否发布回应内容；随后按规则发布日常政府内容、加入普通供给。
6. 排序、消费及互动发生。评价器计算实际曝光 `E_exposure`；发布器统计固定面板互动，生成本tick的 `S_public`和历史窗口包。调查按预定周期抽样本tick消费前的个体偏好。
7. 记录真值、曝光、源信号、已交付信号、政府估计、响应及机制量；信任按本轮经历更新，轨迹中的 `trust_mean`反映更新后状态。
8. 更新个体偏好、衰减热度并清理内容；进入t+1的统一边界。

本tick生成的公开包最早在 `t+1+observation_delay` 可用，调查报告最早在 `t+1+survey_delay` 可用；观察交付延迟与计划行政延迟是两个不同参数。事件中的 `P_trigger/P_execution`均为相应tick开始的评价器真值。

`response_capacity`限制每次监测**新建计划数**，不是每tick执行预算。`hard`、`selective`和`wait`在同一队列接口内工作；执行对象热度、发布开关、触发与到期时间均由事件保留。

## 3 五层对象、公开包与政府权限

| 对象 | 分母/角色 | 主四格政府可读性 |
|---|---|---|
| P，`P_true` | 人数加权潜在偏好，评价真值 | 不可读 |
| E，`E_exposure` | 全体实际曝光次数加权的份额 | 不提供当前总体E或个体曝光日志 |
| S，`S_public` | 固定面板本tick公开互动计数份额 | 生成后经历史包交付才可读 |
| `S_available` | 最新有效已交付窗口信号 | 可读，连同来源窗、组成和时效 |
| P̂，`P_hat_gov` | 受限估计器自身估计 | 可读，另存实际使用证据与更新时间 |

固定面板人数为 `floor(N * sampling_rate)`，面板ID纳入快照。没有面板、缺失或原始总互动为0时，S为NA；不加噪制造活动。有效原始计数可叠加独立正态计数误差并逐话题截断至非负；若加噪后总量仍为0，继续为NA。公开计数可以是实数，噪声尺度不是份额误差。

长度W的窗口按有效tick的公开计数汇总归一化，保存来源计数、分母、权重、有效/缺失tick、覆盖率和warm-up标记。窗口不足W仍按预定W记录覆盖；缺失tick不当作无偏好。包记录 `generated_at/available_at`，接收日志补 `received_at`；包ID变化不代表证据变化。

四格名称的两位依次为PrefInfo、RuleInfo：

| 条件 | 额外获准输入 |
|---|---|
| I00 | 公开包和合法历史公开内容目录 |
| I10 | I00 + 有限独立调查报告 |
| I01 | I00 + 有版本、生效及可用时间的实际排序规则披露 |
| I11 | I00 + 上述调查和规则披露 |

规则披露不提供真实个体曝光概率、隐藏偏好或未来排名；有限调查不提供总体真值。政府输入使用明确类型的白名单，拒绝未获准调查/规则和尚未交付的观测。感知输出保存 `allowed_fields/consumed_fields`、实际包/调查/规则引用、证据签名、更新时间及更新原因。世界中真值日志与可回放政府输入分别保存，政府队列不缓存评价器真值。

没有任何合法偏好观测时，政府保持均匀先验且不触发数据驱动定向回应；常规发布继续。已有合法调查时即使没有公开包，也可以更新并触发回应。先验阶段的感知误差单列，不与有数据估计混为一谈。

## 4 受限反演与解释边界

所有四格拟合同一单纯形候选网格，使用独立固定合成人群作为前向参考；参考个体不是当前世界的真实公众。前向模型以公开内容的话题、情绪、热度及官方来源预测互动组成，行为异质性用固定先验近似。

不透明组在预定规则先验上平均预测；透明组以已披露且适用于来源窗的实际规则替换各先验槽位，保持候选空间和前向调用预算一致。调查在获准时以相同权重加入损失。损失包含公开信号拟合、可用调查及向均匀先验的正则项；并列最优候选取平均。再按 `smoothing`与旧估计加权，只有到更新时间且证据改变才更新。

每次拟合重新使用当前合法输入，重叠历史包不作为相互独立观测累乘。`S_available`可以已变化但P̂尚未更新；`estimate_input_packet_id`表示估计真正使用的包，不能用最新包ID代替。

开发实现用**已交付窗口末的公开内容目录**近似整个历史窗口，规则变更跨窗也记录近似状态。有限网格、有限参考人群、未知抽样选择、未知行为异质性以及Top-K非唯一逆解都可能造成偏差、无收益或反向收益。缺内容目录时模块有明确记录的中性目录回退；这种回退不适合作为正式主实验输入。拟合残差、最优候选数、计算次数和目录/规则状态需要随原始记录保留。

## 5 结果与支持集合

所有分布共用完整话题集合。TV为 `0.5 * sum(abs(x-y))`；距离分别解释，不能相加成为纯机制分解。

| 字段 | 定义与角色 |
|---|---|
| `platform_representation_gap` | TV(P_t,S_public_t)，主1；不把观察陈旧混入源信号差距。 |
| `perception_error` | TV(P_t,P̂_t)，主2；先验阶段单独汇报。 |
| `targeting_error_trigger` | 已执行同批动作的目标向量与触发时P之TV，主3；无执行为NA。 |
| `targeting_error_execution` | 同一目标向量与执行时P之TV；与触发错配之差不是时延因果效应。 |
| `exposure_gap` | TV(P_t,E_t)，架构机制指标。 |
| `visible_signal_current_gap` | TV(P_t,S_available_t)，包括信号的历史陈旧。 |
| `visible_signal_matched_gap` | 以公开包各有效tick互动总量为权重形成窗口匹配P后，与包信号比较。 |
| `signal_estimate_distance` | TV(实际用于当前估计的公开包信号,P̂_t)。 |

按配置固定末窗先汇总世界内均值；tick不是独立重复。记录每项有效tick和缺失比例，主1未达到 `min_signal_coverage`则不可测。世界间配对只用该对比各条件联合可测的母世界，并保留总数、单侧/部分可测、全部不可测和逐母世界差值。四格交互只使用四格共同支持，不能用各格不同支持集合的均值替代。

执行错配在评价窗内按共同触发和共同执行时点组成事件组，以该组各话题动作份额构成目标向量，然后求组间均值；另报动作数、执行发生率、等待和期末pending。它评价回应目标，不等于真实公共服务资源或需求满足。

`response_completion_L`使用预定触发入组窗和固定跟踪L：L内已执行为已完成，完整跟踪但L内未执行为未完成，尚未跟踪满且未执行为右删失。空队列为NA；入组尚不完整或存在未知完成状态时，全队列比率为NA。每项pending保留尚未到期/已逾期，不把尚未观察完的事项记作失败。

`recovery_diagnostic`需要独立健康参考、滚动窗、容差与连续达标长度；缺参考只报告改善，未恢复保留删失和反弹。该辅助函数存在不等于本轮已经运行动态恢复实验。`precision_plan`是未来固定样本量规划工具，当前采用配对样本标准差及联合支持Wilson下界调整；它不是正式覆盖率保证，也不使S0小样本成为独立精度pilot。

## 6 快照、分叉与随机数

快照保存配置/代码/schema/源码哈希、tick/phase、世界及父世界引用、初态哈希、所有个体和内容数组、固定面板、发布器窗口、感知状态、pending回应、未交付包/调查/规则、最新可用信息、内容目录、真值历史与日志前缀。恢复检查规范JSON状态哈希、当前源码哈希、版本、phase和随机协议；代码或NumPy版本变化不能静默恢复旧快照。历史复现必须使用该批实际源码和依赖。

分叉首先从母快照恢复并核对处理前哈希，再只改变允许的处理字段。B0维持母状态政策；B1启动有限调查；B2改新计划行政延迟；B3改新计划排期容量；B4改排序参数或规则。既有计划保留原目标、due和动作参数，新计划才使用分支政策。透明政府按披露时延获知规则变更，不透明政府不因模拟器配置改变而自动知情。

随机协议为 `sha256-seedsequence-pcg64-splitmix64-v1`。命名流覆盖初始化、信任、面板、初始/普通/日常/回应内容、调查、信号噪声、排序、互动和回应决策。每个随机地址由主种子、流名称及tick/对象标识决定，增加或消耗另一流不移动普通供给的抽样位置。元数据记录流名称派生值、协议、NumPy版本和主种子；无顺序游标的流以tick和稳定ID作为地址。

普通内容ID由时间和来源等稳定地址构造；回应内容按时间与话题定位，不使用先前回应数量作为全局计数。排序及互动潜在随机数尽量按 `(tick, agent_id, item_id, purpose)`耦合；只在一条分支存在的内生内容没有强制对应物。日常发布和回应发布是政府行为内容，不能计作普通外生供给。

技术验收需分别证明无干预恢复续跑逐tick一致、fork隔离、干预只改合法字段、旧队列继承，以及同一普通内容的topic/emotion/birth在分支间一致。相同seed本身不构成这些证明。

## 8 S1新增能力与实测

`research_replay.py`冻结经合法输入重新计算的donor计划，保存trigger/target/action参数，只改变due，允许同话题重叠并保留期末删失。接收世界的估计仍独立记录但不控制回放计划。回复采用固定事件身份，跨delay只改出生时间；不承诺相同delay逐tick复刻闭环donor。回放快照必须使用 `ControlledReplayWorld.from_snapshot`，禁止普通自适应fork。

`research_dynamics.py`提供真正保持状态的正反α延续、独立候选参考的同状态恢复和初态/N/T检查。动态检查点保留部分时程，阶段窗口独立登记。`rebuild_dynamics_diagnostics`只使用存档状态重算诊断，不运行仿真tick。参考、恢复时间原点与缩放口径见 [动态说明](s1_dynamic_protocol.md)。

`research_s1_cli.py`以 [S1配置](configs/research_s1.json)运行上述能力和零延迟/heat-off/信任四格。163测试通过，串并行各134份记录（120完整、14检查点），各1,868文件完整性及重建比较通过；见S1报告。`scripts/validate_s1_outputs.py`重建合法感知、排期/回放队列、世界汇总、动态诊断及配对描述，历史S1重建要求匹配完整引擎源码。

## 9 独立精度pilot与实测

[2026-09-30运行前登记](precision_pilot_protocol_20260930.md)及完整配置固定N=100、T=300、α=0.25/0.75、末窗200–299和分叉tick150。61001–61020、61021–61040两批无条件执行，40后停止。两个α复用seed，合计40个独立seed、80个α×seed区组；E2四格、E4五分支、E3闭环五个额外条件及受控回放四条件共1440个物理终点。E3 baseline复用I00，E4 B0与I00续跑一致，均不增加独立重复。
