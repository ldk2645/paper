# S1 动态诊断实现口径

本文件补充 `formal_experiment_protocol.md` 第 8 节和 S1 配置中的实现细节。模块为 `abm_jasss/research_dynamics.py`，全部结果属于开发诊断，`formal_ready=false`。S1 不据此声称已发现相变、滞后、不可逆、稳态或经过验证的健康状态，也不替代独立精度 pilot。

## 调用与预登记

`resolve_dynamics_spec(config, seed, spec)` 只解析和检查设计，不构造世界、不运行 tick。它检查全部动态设置、单调 α 路径、N/T、初态权重、健康候选种子与参考窗、恢复期限和干预字段。S1 runner 在创建输出目录之前调用它；`run_dynamics` 再次复用同一检查。

`run_dynamics(config, seed, spec)` 返回：

- `worlds`：按条件命名的 `ResearchWorld` 对象，供标准原始产物写出器保存。
- `snapshots`：初始状态、母状态、干预前后边界和阶段末状态。
- `diagnostics`：可序列化的登记、哈希、逐窗口结果及限制说明。

默认设置每个种子产生 19 个世界记录：健康候选与恢复母世界各 1 个，α 延续阶段 6 个，恢复分支 3 个，N/T/初态组合 8 个。默认规模只验证实现与数据流程，不是正式实验的规模承诺。

## 保留状态的 α 正反延续

默认路径为 `.25 → .5 → .75 → .75 → .5 → .25`，每段保持 20 tick。返回路径从正向最后一段的完整末状态开始；高端点在返回方向再次保持一段，这一约定在运行前登记。每段通过 `fork` 继承偏好、信任、内容池、热度、感知历史、待执行计划和随机地址协议，再更改 α。已有排队计划保留原定动作参数。

总路径需要 120 tick，因此初始化前将配置时限扩至 `max(原 steps, 路径总长度)`。每段保存输入、继承边界和输出快照，记录母子世界 ID、三个状态哈希及准确区间 `[start_tick, end_tick_exclusive)`。早期阶段的世界包含完整历史前缀，并属于尚未达到配置终点的 checkpoint；该段分析使用单独保存的 `window`，不能把世界配置的最终窗口当作该阶段的观测窗口。

## 独立健康候选与恢复

参考使用独立开发种子，默认将 α 设为 0，其他机制保留。参考配置、种子、区间、曝光差距指标、容差、滚动窗口和连续确认长度均先登记，再运行参考世界。参考值是登记区间内 `exposure_gap` 的均值，要求完整覆盖。低 α 仅是开发阶段的候选来源，不保证该区间具有实质意义上的健康状态。

所有恢复分支共用参考哈希、观察终点和同一母快照。它们分别为保持原机制、将 α 改为 0、开放独立偏好调查；具体干预可以在配置中登记。恢复仍针对曝光差距，不把公开表征差距或感知误差替换成恢复目标。议程曝光份额、公众议程偏好及其他距离同时报告。

在母世界边界 `F` 分叉时，时间零设为最后一个共同完成的 tick `F−1`。初始滚动均值只使用处理前数据；从 tick `F` 开始施加干预。观察终点 `E` 为排他的运行边界，最后可见 tick 是 `E−1`。因此右删失时长为 `(E−1)−(F−1)=E−F`；恢复时长为确认 tick 减 `F−1`。累计超阈偏离沿用 `recovery_diagnostic` 的定义，从时间零的观测值开始累计，包含共同基准 tick。

已经位于健康候选范围内的分支标记 `not_required`；连续规定数量的滚动窗口满足 `gap ≤ g_ref + tolerance` 才确认首次恢复。终点仍未确认则标记 `right_censored`，不是永久失效。恢复后的反弹次数单列，不抹去首次恢复事件。所有这类状态都附带 `conditional_on_candidate_reference=true`。

低层接口允许 `reference=None`，此时仅报告起止改善，不命名恢复；不能把失配母状态的分叉前末窗直接当作健康参考。S1 总入口始终使用已登记的独立候选。

## 初态与 N/T 检查

默认以登记的 `population_weights` 定义均衡与偏斜两类初态，再分别运行 `N∈{12,24}`、`T∈{60,90}`。不改写未登记的个体偏好数组。相同 N、种子和初态的不同 T 运行具有相同初始数组，但这些世界是独立初始化的敏感性检查，不称为 continuation。

普通到达数量与初始内容库存默认按 N 成比例缩放；调度容量默认固定。二者可以各自登记为 `fixed` 或 `proportional`。成比例量按最近整数取整，恰好半整数向上取整，下限为 1；结果同时报告实际人均供给、初始库存和调度容量，因此小 N 取整偏差不会隐藏。常规官方发布保持原间隔。调查样本量取 `min(原调查样本量,N)`，实际值写入登记。

每个世界以配置中的固定末窗计算描述性结果。窗口内有效 tick 数与覆盖率并列；感知误差均值排除无合法数据的先验估计。有限末窗未经额外诊断不能称为稳态。

## 无仿真的档案重建

`rebuild_dynamics_diagnostics(config, seed, spec, world_snapshots, snapshots)` 接收原始世界快照和辅助快照，不读取已保存的诊断数值，也不运行模拟 tick。它校验配置、种子、时点、母子快照连接、继承数组和历史前缀，并从原始轨迹重算健康候选、延续窗口、恢复/删失、N/T 摘要和登记哈希。

输入 `world_snapshots` 的 key 是世界条件名；`snapshots` 的 key 是辅助快照文件名去掉 `.json`。返回值与运行时 `diagnostics` 的规范化哈希应相同。单元测试另外验证：重新计算快照哈希后篡改继承数组仍会被拒绝，重建过程若调用模拟 `step` 则测试失败。
