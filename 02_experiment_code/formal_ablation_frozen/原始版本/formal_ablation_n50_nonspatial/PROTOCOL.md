# 非空间正式消融实验预设协议

## 1. 研究问题与版本边界

本实验严格依据《研究设计.docx》中的非空间版本：所有公众共享同一信息池，不创建空间网格，不设置视野半径，不进行邻域扩散。实验仅用于识别模型内部机制依赖，不解释为现实世界的因果效应。

《研究设计.docx》一处称模型有四个核心机制，另一处的消融表和实验总览却只列出三个被移除机制，并将完整模型计入“四组”。本实验按表格中的可执行定义处理“四组”：

1. `full`：完整模型；
2. `no_emotion`：取消非议程内容的情绪优势，所有自发信息均使用 Beta(2,3)；
3. `no_drift`：偏好漂移速率设为 0；
4. `no_response`：政府回应强度设为 1.0，即回应不再压低热度，回应效果为 0。

信任反馈保持开启（强度 0.25），不另设 `no_trust` 条件。

## 2. 仿真设计

- α 网格：0.00 至 1.00，步长 0.05，共 21 个水平；
- 每个 α×条件重复次数：50；
- 共同随机种子：73000–73049；同一重复序号在全部 α 和全部条件中使用同一随机种子；
- 公众智能体：300；
- 仿真时长：300 步；
- 稳态窗口：最后 100 步；
- 正式运行数：4×21×50=4,200。

## 3. 主要指标

1. `mean_agenda_divergence`：稳态窗口议程偏离度均值；
2. `system_stability`：稳态窗口议程偏离度的总体方差；
3. `storm_time_share`：稳态窗口处于舆情风暴状态的时间比例；
4. `mean_trust`：稳态窗口公众平均政府信任。

## 4. 临界点

对每条 α–议程偏离度曲线进行三点居中平滑，在内部网格点中寻找最大正数值斜率。完整模型临界 α 是主要比较位置；各消融条件的临界点只作描述性结果。

95% 区间采用 5,000 次“种子整条轨迹”区组 Bootstrap：每次抽取种子后，保留该种子在全部 α 下的完整曲线。若指标范围低于 0.015 或不存在正内部斜率，则不识别临界点。

## 5. 消融效应与统计推断

在相同 α、相同种子下计算 `消融−完整模型` 的配对差：

- 全 α 输出均值差、配对 t 检验、Wilcoxon 符号秩检验、Cohen dz、Hedges gz、秩二列相关和 10,000 次配对 Bootstrap 95% 区间；
- 在完整模型临界 α 对 3×4=12 个主要比较进行全局 Holm 校正，并补充 99,999 次符号翻转检验；
- 对每个种子的 21 点曲线计算梯形积分 AUC，形成 3×4=12 个跨曲线配对比较，并进行全局 Holm 校正和 99,999 次符号翻转检验；
- 所有区间均为逐比较区间，不是跨 α 的同时置信带。

## 6. 可复现性与排除规则

- 正式运行必须记录模型、运行器、研究设计文件的 SHA-256、Python/NumPy/Pandas 版本、完整配置、种子和运行签名；
- 原始 CSV 不覆盖历史探索性数据；若检测到运行签名不一致则停止；
- 只排除非有限数值、缺失主键或重复主键；不依据结果大小排除模拟；
- QA 必须验证 4,200 行、每格 50 次、84 个 α×条件单元、共同种子、主键唯一、配置签名一致和统计输出完整。
