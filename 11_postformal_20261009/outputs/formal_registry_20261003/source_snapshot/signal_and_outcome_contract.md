# 公开信号、政府感知与结果指标合同

计划修订：2026-09-27 r2。状态：**待实现、待验收，formal_ready=false**。本合同落实[技术补充与作用说明](planning_inputs/ABM_技术补充与作用说明_20260927.md)，细化[正式实验协议](formal_experiment_protocol.md)的观测与指标口径，不新增理论机制。原始材料按参考意见评估；其中不充分的示例及开发顺序不直接照搬。

本轮确定的关键改变是：把公开互动信号S从实际曝光E中拆出，主指标1改为公开表征差距，曝光差距保留为架构机制指标。当前0.4.0的代码、480个开发世界及43项历史测试均未因此升级。新指标必须重新生成原始记录并经过独立精度pilot，不能重命名旧输出来补齐。

## 1 五层对象及时间语义

| 符号与拟议字段 | 生成者与含义 | 政府访问 |
|---|---|---|
| P_t，`P_true` | 评价器：tick t开始、消费及偏好更新前的总体平均潜在偏好 | 主四格禁止；有限调查不等于直接提供P |
| E_t，`E_exposure` | 平台内部：本轮实际消费曝光的分话题份额，以曝光次数为分母 | 不提供完整个体日志或当前总体E |
| S_public_t，`S_public` | 公开信号发布器：本轮消费后生成的公开分话题互动计数份额，来源范围及噪声固定 | 只能在后续合法交付后读取；生成不等于当轮已可读 |
| S_available_t，`S_available` | tick t决策时最新已交付、有效的历史窗口公开信号 | 可读；须带来源窗、交付时间、是否沿用旧包与年龄 |
| P̂_t，`P_hat_gov` | 政府：受限估计器以已送达公开信号和获准额外信息计算；非更新轮保持 | 自身状态可读；保存输入引用及更新时间 |
| R_u，`response_events` | 政府：触发τ、计划到期和实际执行u及目标；不称服务资源分配 | 读取自己的队列与历史；评价器补写的P不可回流 |

P、E、S和P̂均使用同一完整、互斥的话题taxonomy。P是人数加权的偏好，E是曝光加权的注意力，S是互动加权的公开显著性；相同话题支持允许比较组成距离，但不使其分母、人口覆盖或规范含义相同。有效分布须非负、有限、总和为1；无有效观测是NA，不强制归一化。

概念链保留P→E→S→P̂→R；时序上，tick t产生的公开信号最早进入d≥t+1的决策，再于u≥d执行。零行政延迟只允许u=d，不能让政府读取同轮尚未产生的E或S。完整系统状态记X_t；偏好/规则信息因素记PrefInfo与RuleInfo，I00/I10/I01/I11的位序依次为二者。S不再兼指调查处理或snapshot状态。

## 2 最小公开信号生成与交付

主实验固定为**分话题公开互动计数份额**。趋势榜、热度存量和曝光日志可以成为另外的结构稳健性版本，不能在同一主指标内随意替换。

1. `sampling_rate`控制发布器的观测面板，主方案在初始化时按固定人数简单随机抽样，固定面板ID；人数取floor(N×rate)，rate=1覆盖全体，0人返回缺失。面板选择使用独立随机流并纳入snapshot。面板只提供聚合互动计数，不向政府暴露个体E、偏好或信任。
2. 记录本轮各话题原始互动数`engagement_count_raw[t,k]`及总数。主基准`observation_noise=0`。噪声敏感性候选采用计数尺度的非负截断：C_pub[t,k]=max(0,C_raw[t,k]+ε[t,k])，ε来自独立的零均值正态发布误差，标准差σ以“每话题每tick互动次数”为单位。σ、截断规则及流身份在精度pilot前登记；不以噪声制造预定组间差异。
3. 无面板、缺失或原始总互动为0时标为无观测，不用发布噪声制造虚假活动。有效原始计数加噪后若总和为0，仍为NA。否则保存C_pub及其分母，S_public[t,k]=C_pub[t,k]/Σ_j C_pub[t,j]。非零噪声下公开计数可为实数，必须标注发布机制，不冒称实际次数。
4. 每tick末生成一个历史窗口包，窗口[a,b]=[t−W+1,t]；不足W的启动窗标为warm-up并记录实际覆盖。在窗口内只汇总有效tick的公开计数，缺失tick不当作“无偏好”。记录有效tick集合、缺失比例与各tick总量；至少一个有效tick才形成有效分布。窗口S按汇总计数归一化。数据不完整时照实报告覆盖，评价窗的最低覆盖要求须在正式冻结前确定。
5. 该包`generated_at=t`，最早`available_at=t+1+observation_delay`，其中额外交付延迟≥0；政府在tick开始才接收已到期包。W是`observation_window`，交付延迟与行政延迟分离。
6. `S_available`是当前最新有效已交付包；没有新有效包时保持上一次有效包，记录已合法送达的缺失状态、沿用情况和包年龄，不能伪装为新观测。本轮消费后才产生的缺失只由发布器/评价器当轮记录，不提前通知政府。尚无有效公开包时S_available为NA，但已经收到的合法调查仍可独立更新估计和触发回应；只有缺少任何合法偏好观测时保留明示先验且不触发数据驱动定向回应，规则披露本身不算偏好观测。常规官方发布继续。主方案无静默过期或隐式重置；最大允许年龄如作敏感性必须单独登记。

不将任意排名、可负趋势指数直接归一化后计算TV。若未来只公开Top-k，必须提供有定义的“其他”质量并统一taxonomy，或明确不可计算完整组成距离；未披露项不能自动记为真实0。

## 3 感知更新与信息对照

发布器与政府估计器分开。`public_signal_publisher`可以在平台内部读取被授权采样对象的互动事件，但交出的packet只含白名单字段；`government_sensing`不能读取发布器内部状态。`observation_noise`、`sampling_rate`位于发布层；窗口在历史包构建层；`smoothing`和`update_frequency`位于估计层，不能用同一个参数同时改变多个层。

政府在预定更新tick调用统一受限估计器得到候选p̃，采用P̂_new=(1−λ)P̂_old+λp̃，0<λ≤1。λ=1是不平滑基准。以有效源tick及其公开计数版本、调查报告和规则披露版本计算`evidence_signature`；同一证据重发或换packet ID不算新信息，不能重复平滑。窗口中实际证据集合改变（包括旧记录退出）、新调查或规则披露可在下一更新轮重新估计。该方案不把连续重叠窗口当作相互独立的贝叶斯观测反复累积似然；p̃每次基于当前合法输入重新拟合，历史保留作用由明确的平滑状态承担。未到更新时间则保持估计。过渡期prior及首个更新规则明确登记，不隐式更换。

保存`estimate_input_packet_id`、`evidence_signature`、调查/披露引用、`estimate_updated_at`、候选估计、最终估计、是否更新及原因。最新送达包与实际估计所用包可能不同，二者不能共用一个含混的packet_id。动作事件引用该次决策实际使用的估计与信息组合。

E2四格使用相同公开信号**构建规则、观测资源、推断框架和预算**。冻结同一组公开packet的估计器构造测试，可以要求输入历史完全相同；有政府反馈的四个世界，后续实际互动与信号可能因处理而分化，不能一边允许反馈一边声称实现历史始终相同。公开历史分化是闭环效果的一部分，另用固定packet回放诊断信息的直接推断作用。

PrefInfo=1提供有限调查；RuleInfo=1披露排序规则/参数并进入相同推断程序，均不额外泄露真值。偏好oracle只作理想信息基准；同一时点、同一口径的精确P可令相应感知误差为0，却不保证回应、恢复或其他政策效果最优。

## 4 新指标字典与旧证据隔离

| 拟议字段 | 定义 | 角色与解释 |
|---|---|---|
| `platform_representation_gap` | TV(P_t,S_public_t) | 主1：同轮公开表征差距；源信号在消费后由评价器记录，不提供给本轮政府决策 |
| `perception_error` | TV(P_t,P̂_t) | 主2：当期政府感知误差，含历史信息/更新造成的陈旧 |
| `targeting_error_trigger` | 已执行同批动作r与触发时P的TV | 主3：条件回应目标错配；无回应NA，与执行发生率联合呈现 |
| `exposure_gap` | TV(P_t,E_t) | 关键机制指标：实际注意力分配偏差；继续用于架构恢复主判据 |
| `visible_signal_current_gap` | TV(P_t,S_available_t) | 政府现时可见表征与当期偏好的差，包含公开信号偏差和历史窗口陈旧 |
| `visible_signal_matched_gap` | TV(P_ref_packet,S_available_t) | 对齐来源窗的描述性差距，不能单独识别算法偏差 |
| `signal_estimate_distance` | TV(S_used_t,P̂_t) | S_used是当前估计实际使用的公开包，非当前E、也不一定为最新送达包；有调查时仍只是公开基准距离 |
| `targeting_error_execution` | 同批已执行动作r与执行时P的TV | 对照触发错配，差值不称行政延迟因果损失 |

TV(x,y)=0.5Σ_k|x_k−y_k|。按冻结评价窗先求世界内有效tick均值，再比较世界；记录有效tick数及缺失比例。共同有效tick诊断与全窗覆盖并列，不能把缺失当0，也不把每个tick当独立重复。主3按事件组计算，联合可测支持规则保持正式协议§1/§7不变。P̂尚为先验时单列标记，不与有数据更新阶段混称观测精度。

窗口匹配真值仅由评价器产生：令V为packet[a,b]内有效tick集合，w_s=Σ_k C_pub[s,k]/Σ_{v∈V,k} C_pub[v,k]，P_ref_packet=Σ_{s∈V} w_s P_s。V为空则NA。相同权重匹配的是时间构成；P_s仍为总体偏好，未消除面板覆盖、活跃度选择、互动机制和噪声。原始总量、权重、窗口及每tick真值引用均保存，P_ref_packet不得回流政府。

主1采用同轮源信号，是为了不将观察窗口陈旧全部命名为平台表征失真；决策时真正可见信号则用两个visible_signal诊断明确报告。这一选择须在正式数据前冻结。三层距离不是可加误差分解；D(P,P̂)−D(P,S)和窗口匹配差不能当作纯感知/时延效应。

**历史字段映射仅用于阅读旧结果**：0.4.0的`attention_k`对应实际E，`truth_k`对应当期P，`estimate_platform_k`是当时的估计器输出。在480世界的特定配置中估计直接复制当期曝光，所以前两层相等；这不等于已经记录了独立S_public。原CSV、旧图及后处理保持原名称和语义，不推填或重命名为新主1。新schema使用完整`platform_representation_gap`，不复用旧含混`representation_gap`。

## 5 回应完成、等待与恢复

主3的执行条件性、目标向量及NA规则继续沿用正式协议。补充`response_completion_L`：先冻结触发队列入组窗[τ0,τ1]及固定跟踪长度L，分母为该窗内全部新建计划，分子为满足0≤execution−trigger≤L的执行计划。同一计划不重复计数，计划观察期须至少覆盖τ1+L；所有政策使用相同入组窗和L。分母为0则NA。

若记录提前结束，L内已执行的完成状态仍已知；只有未执行且尚未跟踪满L的计划才是完成状态未知/右删失。有未知状态时全队列固定L完成率标为不可完整估计，并分别报告已完成、完整跟踪未完成、未知/右删失，以及尚未到期和已逾期数量。完整跟踪到L仍未执行，表示“L步内未完成”，不是永久失败。期末全部pending继续保存，不以只纳入成熟队列的比率冒充全队列完成率。无行政执行预算的当前设计中，增加排期容量也可能只增加动作数，完成率未必变化，零差异有效。

`unmet_priority`仍为可选辅助指标，共同参考事项集合改记J，避免与曝光E混淆；不能以各分支自身触发队列作为分母，也不能据模型热度动作声称真实需求已经满足。

架构恢复主判据明确使用`exposure_gap`相对独立健康期/扰动前基准的连续达标；新主1的加入不暗中更换这一物理目标。公开信号和感知的恢复若另报，必须各自登记健康参照与持续窗口。没有健康基准只报改善；未恢复右删失；已失配的分叉前末窗不自动成为健康期。

## 6 接口、原始产物与必须通过的验收

未来产物按角色隔离：`public_signal_ticks`保存计数/分母/状态和公开源信号；`observation_packets`保存完整窗口组成、generated/available/received时间；`government_estimates`保存实用包和估计更新；`evaluator_trajectory`保存P/E及各距离；`response_events`保存计划/执行/删失及评价器专用P；`snapshot_manifest`保存X、流状态、包缓存、面板及ID。文件名可变，schema、权限和引用关系不得省略。动作日志中的真值应与可回放给政府的公共日志分开。

材料所列14项验收落为下表；这些是**拟议验收，当前尚未运行**。

## 7 开发依赖与范围

顺序为：冻结本合同/权限/tick → 公开信号与独立感知 → 稳定ID、随机流映射/状态和共同冲击基础 → 完整snapshot/restore/fork → 2×2与五分支及原始结果 → 权限/恢复/记录测试和S0 → 零行政延迟、full heat-off、最小信任及S1 → 独立精度pilot → formal设计与新种子冻结 → 正式运行。时序合同从最初统一制定，零值支持可以后续验收；RNG的fork依赖不能等到S0之后才处理。

保留原五项创新和七章论文结构；不新增learning cost、数字政府指数、agent类型、信任方程或综合绩效指数；不拟合旧α阈值。旧代码、历史数据及不符合预期的结果均保留。下一步是实现上述识别与复现层，不把本次计划修订写成模型已通过正式验收。
