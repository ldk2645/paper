## 2 设计与计数边界

使用 [research_s0.json](configs/research_s0.json)：N=24、T=60、末窗 20 tick、分叉边界 t*=30，α∈{0.25,0.75}，开发种子 51001–51003。调查样本为 8；反演网格为 4、参考人群为 4。

每个 α×seed 区组运行 I00/I10/I01/I11；I00 在 t=30 保存母状态，分 B0（原政策）、B1（开启调查）、B2（新计划延迟降为 1）、B3（新计划排期容量增为 2）、B4（α降为 0）。既有队列保持原 due 与动作参数。

共有 6 个母状态，但仅 3 个开发种子，并且同种子跨 α 复用初态。30 条分支后缀不等于 30 个独立母世界；串行和并行也不是新增统计重复。E4 raw 保留继承的历史前缀，评价末窗在分叉后，完成率入组窗单独从分叉后开始。

每批保存 3,240 条轨迹记录、2,715 条回应事件记录及期末 145 条 pending 记录。它们包含 E4 继承前缀和各分支记录，不能解释为独立发生的 2,715 次动作。pending 保留为未到期记录，不自动记为完成率失败。

三个主指标及完成率在这批 E2 的 24/24、E4 的 30/30 记录中均可测。各 α 内的主指标配对与交互具有 3/3 共同支持。这只描述此次小批次的支持集合，不能据此假定正式实验没有缺失；零信号、无执行和右删失仍通过独立构造案例验证。配对文件保留逐区组值及缺失模式，不报告 S0 推断区间或显著性。

| 要求 | 实际证据 |

| P/E/S/P̂ 分层与权限隔离 | 四格授权字段及实际消费字段测试；新增真实 world→感知→队列检查：改变隐藏偏好和旧评价 P/E、固定合法输入后，估计和新计划相同 |
| 公开 S 可独立于曝光 E 变化 | 新构造保持 P、E=[0.5,0.5]，交换两组人的互动倾向，产生有效 S=[1,0] 与 [0,1] |
| 包交付、实际引用、零计数与先验 | 信号/感知/世界测试及产物交叉引用；无合法偏好观测不触发定向回应，合法调查可独立驱动估计 |
| 同证据不重复平滑 | 包 ID 更换、调查重发的既有规则；新增同规则重交付回归，并确认规则实质改变仍更新 |

| 恢复与分叉 | 逐 tick snapshot 恢复测试；6 个区组分别通过续跑、B0 全日志、母状态隔离、共同处理前哈希、旧队列继承检查 |

| 无漂移与无回应 | 固定偏好检查；无定向回应保留日常发布、目标错配保持 NA |
| 缺失/删失与聚合 | 零信号、无动作、完成率未满 L、共同支持和四格交互构造；从 raw 重建全部汇总 |
| 产物完整性与复现 | 新增校验器/比较器集成测试：只读性、篡改/缺失/额外文件、重算哈希后的语义不一致、版本不匹配均拒绝 |

本轮修复两处实际缺陷：

1. 校验器重建 E4 默认 `completion_end` 时，原先先按母世界入组起点计算，再移动分支起点，可能误拒合法批次。现先确定分叉后起点，再解析默认终点；长跟踪期且省略终点的回归通过。
2. 感知器将规则的 `available_at` 纳入证据签名，导致同一规则仅重新交付也被再次平滑。构造案例曾使估计从 [0.6,0.4] 变为 [0.65,0.35]。现排除交付时间，保留版本、生效时间及规则内容；重交付保持估计，实质规则变更仍更新。

上述修复后才启动两个完整 S0 批次。历史 0.3/0.4 输出未改写。包的旧入口版本仍为 0.4.0，新识别引擎独立使用 `RESEARCH_VERSION=0.5.0-dev` 和 `research-1` schema。
