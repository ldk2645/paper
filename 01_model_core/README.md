# 冻结核心模型

`model.py`是本发布包唯一的核心模型快照，SHA-256为：

```text
AB78E6C64AFB6FD487E40A48FBBCD1B09A84EE3FBC9085530F8833DE3543D7EC
```

模型实现政府、平台和公众三类主体，以及信息生成、热度—偏好推荐、情绪互动、偏好漂移、政府监测与延迟回应、学习成本、政府信任、热度衰减和低热度清理。所有公众在同一当步信息池中获得个体化排序。

正式S2运行器通过导入这个文件建立模拟。参数敏感性只构造不同的`SimulationConfig`；三种顺序检验只在运行器中重排现有步骤，不回写本文件。

该模型是机制实验工具。参考论文的部分系数用于关系方向和相对强度的先验锚定，不能解释为本项目重新估计的因果系数。完整公式、系数来源和逐步顺序见`../05_documents/附录A_B_模型公式与指标.md`。
