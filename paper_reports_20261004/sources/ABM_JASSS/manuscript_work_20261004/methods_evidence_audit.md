# Methods evidence audit — 2026-10-04

Scope: read-only audit of the existing [Chinese Methods draft](../manuscript_methods_formal_20261004.md) against the registered E2/E3/E4 design, implemented ODD, research-engine description and configuration. This file supplies checked wording for an English translation; it is not a new experimental protocol, analysis, validation report or Results section. No formal outcome values or partial-batch statistics were inspected or generated. No model, frozen contract or raw artifact was edited.

The existing Methods draft is a suitable source for translation. No substantive contradiction was identified in its design counts, outcome definitions, joint-support estimand or registered inference rules. The wording refinements at the end address clarity and model-description completeness rather than changes to the frozen design.

## Recovery, reproducibility and limits

The [repair-resume protocol](../formal_numeric_repair_resume_protocol_20261003.md), sections “Numeric policy retained”, “Direct reconstruction of successful groups” and “Validation and release gates”, supports the following wording:

> The registered recovery retains the physical model, configuration, random addressing and inferential design. Successful groups reuse byte-identical compressed raw records and snapshots; pure functions regenerate batch metadata and derived artifacts without advancing physical worlds. The failed mother block is rerun in full using its original seed and configuration. Recovery adds no independent samples. A documented absolute tolerance of 1e-12, with relative tolerance zero, permits correction of verified floating-point boundary excursions in a temporary derived distance view; raw values and probability vectors remain unchanged. Invalid vectors, inconsistent reconstruction and excursions beyond tolerance are rejected. Formal analysis is released only after complete read-only semantic validation bound to the current manifest and artifact inventory.

This is a description of the authorized procedure, not an assertion that the active batch has completed it. The manuscript should update completion status only from final acceptance evidence.

Limitations already correctly retained in the draft should survive translation: fixed N/T/supply scale; finite candidate and reference populations; window-end catalogue approximation; possible nonidentification; no real-world calibration from synthetic internal validation; conditional support; approximate t inference; fixed-budget precision shortfalls; absence of registered cross-alpha inference; and no formal E5 transitions/recovery or E6 trust prediction in this batch. Two alpha values do not identify a critical threshold, monotonicity, hysteresis or irreversibility. Lower distances or greater agenda exposure do not establish public welfare improvement. See [formal protocol, Auxiliary results and stage boundaries](../formal_execution_protocol_20261003.md), [ODD, §6](../ODD_research.md), and the [paper outline's 2026-10-04 update](../paper_outline_jasss.md).

## Specific drafting refinements

1. At line 24 of the [existing Methods draft](../manuscript_methods_formal_20261004.md), replace the table label “普通信号发布” with “平台公开信号”; translate it as “Public platform signal”. “Ordinary signal” could incorrectly imply that interactions with official content are excluded.
2. The model paragraph at line 7 and settings at lines 17–30 are accurate but compact. For an English standalone Methods section, add a short mechanism paragraph or an explicit supplementary-ODD pointer covering the alpha-weighted heat/similarity score, heat reinforcement and decay, the retained preference-drift rule, the hard response threshold, separate routine/reply publication and trust feedback. These describe existing mechanisms; do not introduce new equations or claim new ablation evidence. Useful registered values include response threshold 0.15, response heat retention 0.7, routine publication interval 10, drift rate 0.03, drift threshold 4, trust update rate 0.06 and trust feedback strength 0.25; see the [configuration](../configs/formal_design_20261003.json) and [ODD, §6](../ODD_research.md).
3. The estimator paragraph at line 32 is accurate. If space permits, expose the opaque alpha prior {0, 0.5, 1}, regularization 0.01 and synthetic reference seed 1729 in a supplementary parameter table, and state that overlapping historical packets are not multiplied as independent observations. These points are documented in [research engine, §4](../research_engine.md).
4. Preserve the existing distinction between terminal-window execution inclusion and trigger-time truth for primary 3. A shortened translation such as “responses triggered in the final window” would change the registered estimand.
5. Preserve the existing line-67 distinction between independent seed units and paired worlds. Prefer “independent mother-seed units” rather than “independent worlds” when reporting the full 1,184-block design.
6. Preserve the opening “registered roster” qualification and the conditional release wording in the recovery section until whole-batch acceptance is available. Do not convert counts of planned endpoints into claims of accepted simulations merely by changing tense.

No edit to the frozen sources or the existing Methods draft was made by this audit.

## English-draft follow-through, 4 October 2026

The subsequent [English Methods draft](methods_en.md) and [Results evidence map](results_evidence_map.md) were reviewed against the same frozen design. The drafting refinements above were applied where relevant. A second read-only review found no material mismatch in the registered design or replication counts. Three wording refinements were then applied: perception-error eligibility explicitly uses the data-based estimator state (`has_data=True`), rather than information delivery alone; the numeric repair clamps only verified scalar boundary distances in a derived view, without renormalizing vectors or changing raw values; and unavailable inference retains missing values and reasons rather than fabricated intervals or p-values. These are manuscript changes, not changes to the frozen model, estimands or running batch. Formal result release remains conditional on final batch acceptance.
