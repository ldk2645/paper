# 文档阅读顺序

1. `研究设计.docx`：研究问题、实验框架和正文对应关系。
2. `附录A_B_模型公式与指标.md`：完整公式、全部系数、三主体行动顺序、逐步和汇总指标、正式统计方法。
3. `补充材料S1_外部验证细节.md`：公开数据来源、转换、完整回归、15项相关、HC3、逐国剔除和注意力衰减。
4. `补充材料S2_敏感性分析.md`：14组参数扰动、三种执行顺序、三种内置回应策略和无有效回应参照。
5. `FIGURE_LEGENDS.md`：主图、Extended Data和补充图的投稿图注。
6. `ADD_REQUIREMENTS_TRACEABILITY.md`：把原始补充要求逐项映射到文档、数据、代码和QA证据。

S1与S2均保留统计边界和失败/空结果，不把公开数据一致性写成因果验证，也不把临界点不移动误写成机制没有作用。
